# Emberbrook · 餘燼溪谷

A small, illustrated single-player fantasy adventure made for GitHub Pages. The first chapter is a playable art-focused prototype, not a multiplayer service.

## Play

Live: https://ymhomer.github.io/Emberbrook/

For the ready-to-play ZIP, extract all files together and open `index.html` in a modern desktop browser. If your browser restricts local files, use the GitHub Pages build or a local static preview. Do not open the HTML directly inside a ZIP.

- **WASD / arrow keys**: move.
- **Click / tap ground**: walk there using pathfinding.
- **Click a map marker**: walk there and interact.
- **E**: interact with a nearby object; **Space**: attack in the Hollow.
- **I**: satchel; **J**: journal; **2**: forge.
- **中 / EN**: Traditional Chinese / English.
- **Moon**: toggle dusk lighting; **speaker**: toggle short synthesized action sounds. No external audio files.

**First chapter:** gather 3 timber and 2 iron ore from marked deposits → visit Bram's forge and spend 30 gold to craft a blade → enter the mine → defeat three wisps → take the relic at the altar → return it to Bram. Deposits replenish after a short pause. Rest at the inn or well to recover health.

Use the minimap's expand button for an illustrated atlas: select a landmark, preview the route, then confirm your destination. The bottom Forge button opens the crafting panel and offers to walk to the forge if you are far away. Mobile has an analog touch joystick, tap-to-walk, and on-screen E / attack buttons. Release the joystick to stop; manual movement cancels an automatic route.

## Willowmere Woods (0.3)

Walk to **Trail to Willowmere** at the southern village gate using the atlas. In the new woodland, gather moonleaf herbs and play the fishing timing challenge at the pier. Deliver 2 fish and 3 herbs to the ranger for 65 gold, 35 XP and a healing draught; repeat as often as you like. The first delivery unlocks a one-time shrine restoration reward. Drink draughts from Inventory to recover 50 HP, or rest at the campfire. The original chapter and existing saves remain available.

## Saves

Progress saves automatically every five seconds and after important actions. The Save button saves immediately. **Journal → Adventure & settings** offers save export/import and a confirmed new-game reset.

Saves are browser-local and origin-specific, with no account or cloud sync. Export before changing device/browser/URL or clearing browser data. A locally opened copy and a GitHub Pages copy do not share saves automatically. If browser storage is blocked, use export.

## Develop

Node 24 and project-local npm dependencies:

```sh
npm ci --ignore-scripts
npm run check
npm test
npm run build
```

`dist/` is the complete static release. It bundles Phaser and font data, with no CDN or server-side runtime. All asset paths are relative, supporting a GitHub project subpath. Direct file opening uses Canvas for compatibility; hosted builds automatically select the available renderer.

Optional automated browser QA uses Playwright. The local Linux test environment setup and observed results are in `ENVIRONMENT.md` and `docs/BROWSER_VALIDATION.json`; installing or starting a browser is not needed to play the game.

## GitHub Pages

1. Put this source project in your chosen GitHub repository on branch `main`.
2. In **Settings → Pages → Build and deployment**, choose **GitHub Actions**.
3. Push the source. The included `.github/workflows/pages.yml` runs checks/build and publishes `dist/`.
4. The resulting address is normally `https://YOUR-NAME.github.io/REPOSITORY/`.

Alternatively, commit the contents of the ready-to-play ZIP to a Pages deployment branch and use **Deploy from a branch**. Keep the asset and vendor directories with `index.html`.

No repository was created or published as part of preparing this local test build.

## Art and scope

- Two original AI-assisted illustrated map backgrounds, compressed as WebP; source generation masters are retained only in local artifacts.
- Original transparent 16-frame pixel character and NPC sheets, portrait and small item sprites, generated by `scripts/make-sprites.py`.
- Animated actors, gathering, world-space collisions, pathfinding, smoke, sparks, water highlights, floating motes and combat effects are separate from the map paintings.
- Single hand-authored village and shrine; one small quest, lightweight combat and crafting. No multiplayer, server economy, procedural world or full building system in this prototype.
- Phaser is MIT licensed. Bundled Noto Sans TC and Cormorant Garamond subsets are under SIL OFL; licenses and source hashes are included.
