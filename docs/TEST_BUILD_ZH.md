# 餘燼溪谷 — 第一版測試說明

## 開始

解壓可玩包的全部內容，雙擊 index.html。不要直接在 ZIP 裡開檔案。桌面建議使用 Chrome 或 Edge；若本機安全設定限制 file://，請部署 GitHub Pages 後測試。

右上角「中」切換繁體中文。「中」切換只影響介面，遊戲名 Emberbrook 與角色名 Rowan 保留。

## 5–10 分鐘測試路線

1. 點小地圖右下角的展開符號，從地點按鈕選採集木材。
2. 到達採集點自動取得一份；稍等兩秒後按 E，可繼續採集至三份。也可以尋找另外的木材堆。
3. 同樣收集兩份鐵礦石。
4. 前往鐵匠鋪，鍛造餘燼鋼劍。需要 3 木材、2 礦石與 30 金幣。
5. 前往地圖右上方礦坑，選進入幽谷。
6. 使用移動與空白鍵攻擊，擊敗三隻幽光。手機可用右下角攻擊按鈕。
7. 前往上方祭壇取得遺物，從下方入口返回村莊。
8. 回鐵匠鋪交還遺物，完成第一章。

角色受傷後可到旅店或水井休息。體力耗盡會返回村莊，不會永久失去角色。

## 這次希望你看什麼

- 村莊與地城的美術風格、人物比例、畫面密度與介面文字大小。
- 角色移動、路徑與採集點是否好理解。
- 鍛造、戰鬥、章節目標和繁體中文介面是否清楚。
- 重新開啟後能否恢復存檔；是否需要改成更方便的存檔入口。

本機存檔沒有雲端同步。日誌 → 冒險與設定可匯出／匯入。換瀏覽器或部署網址前請先匯出。

這是可玩美術原型：沒有多人、登入伺服器、完整城建或大量任務。GitHub Actions 發布流程已備妥，但尚未對外發布。


## 0.3 柳澤森林

從地圖選「前往柳澤的小徑」，走到村莊南方的門後進入。採集 3 份月葉藥草，在碼頭釣 2 條魚，交給巡林人換取金幣、經驗與治療藥劑；委託可重複完成。第一次交付後可修復神龕。釣魚時讓浮標進入金色區域再收竿；藥劑在背包內使用。原存檔繼續有效。
